# 灵感绘境 · MuseFrame Studio

灵感绘境是一个角色与场景提示词工作台。你可以从内置方案开始，调整五官、发型、服装和环境，再生成可复制或下载的提示词，供外部图像生成工具使用。

[打开在线工作台](https://sumingworks.github.io/MuseFrame-Studio/)

## 本地使用

下载或克隆仓库后，用现代浏览器打开根目录的 `index.html`。项目使用 HTML、CSS 和原生 JavaScript，无需安装依赖或构建。

注意：`file://` 和 `http://127.0.0.1` 属于不同的浏览器存储域，草稿、个人方案和自定义词库不会自动互通。需要迁移时，先在旧页面使用「备份全部方案与词库」，再在新页面使用「恢复完整备份」。

```bash
git clone https://github.com/SuMingworks/MuseFrame-Studio.git
cd MuseFrame-Studio
```

## 工作台流程

1. **人物设计** · 从内置角色方案开始，或逐项选择并编辑人物参数。
2. **画面设计** · 选择四视图设定图、单人全身立绘、面部肖像特写、三姿态展示、场景氛围海报或服装细节展示，再设置画幅、分辨率建议和画质。
3. **场景设计** · 在右侧点击场景卡片，或用下拉框选择地点。可继续调整时间、天气、光照、景深和道具，也可编辑场景核心提示词。已配置图片的地点支持全屏预览。
4. **场景融合** · 设置场景在画面中的比重，以及人物动作、位置和环境受光。生成内容会随出图模式调整。
5. **生成输出** · 生成并复制提示词，或下载 TXT。需要复用当前参数时，可下载 JSON 配置并在以后导入。

## 方案、草稿和备份

人物下拉词条可作为编辑起点。手动修改后的文字会用于当前出图模式采用的字段。场景自定义文字会在启用场景时加入提示词。

草稿、个人方案和自定义词库保存在当前浏览器。用「另存为新方案」保存新的个人角色，或用「保存修改」更新已有个人方案。换浏览器或设备前，可在「我的方案」中点击「备份全部方案与词库」，再用「恢复完整备份」导入。

## 项目文件

| 路径 | 用途 |
| --- | --- |
| `index.html` | 工作台入口 |
| `styles/studio.css` | 页面样式 |
| `scripts/` | 人物编辑、场景设置、提示词生成、方案存储和流程导航 |
| `images/characters/` | 人物方案预览图 |
| `images/scenes/` | 场景预览图 |
| `images/favicon.svg` | 浏览器标签页图标 |
| `人物设定.txt`、`场景设计.txt` | 人物与场景的预设录入模板 |

内置人物方案位于 `scripts/character-editor.js`，人物字段选项位于 `scripts/character-schema.js`。场景地点及分类位于 `scripts/scene-settings.js`，内置场景模板位于 `scripts/scene-library.js`。场景预览图放在 `images/scenes/`，文件名需与地点名一致。

## GitHub Pages

在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，将发布来源设为 `main` 分支的 `/(root)`。部署完成后，可从 Pages 设置打开站点。
